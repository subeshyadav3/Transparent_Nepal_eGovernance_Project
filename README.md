# 🏛️ Transparent Nepal (सफा र पारदर्शी नेपाल) 🇳🇵

**Transparent Nepal** is a next-generation e-governance platform developed for the **Digital Nepal Framework Initiative**. Moving beyond simple records, it serves as a "Trustless" central hub for tracking federal budgets, provincial spending, and national infrastructure projects, ensuring absolute accountability through the Open Data Initiative.



## 🏗️ Project Vision
Our goal is to ensure a prosperous Nepal through digital transparency. Every taxpayer has the right to know where their money is being spent—from National Pride Projects to local community renovations. By digitizing the audit trail, we eliminate the "dark corners" where corruption usually hides.

## 🚀 Core Features

### 🏛️ Admin & Government Portal
* **Immutable Budget Entry:** Tools for departmental budget allocation with version history.
* **KYC Verification:** Secure queue for reviewing and approving citizen identity documents to ensure real feedback.
* **Project Oversight:** Real-time progress updates for infrastructure projects with mandatory "Reschedule Logs."
* **Contractor Accountability:** Performance scoring and registration management for vendors to prevent blacklisting bypasses.

### 👥 Citizen Engagement Portal
* **Live Spending Tracker:** Real-time data visualization across all 7 Provinces and 753 Local Levels.
* **Verified Grievance System:** A KYC-backed complaint system (Hello Sarkar 2.0) that cannot be ignored or deleted.
* **Public Pulse & Voting:** Citizens can "Upvote" or "Downvote" projects based on real-ground progress.
* **Open Data Analytics:** Deep insights into fiscal efficiency, preventing budget "leakage."

## 🛡️ Data Integrity & Trust (Anti-Manipulation)
Unlike traditional systems, **Transparent Nepal** is designed to prevent data tampering:
1. **Public Audit Trail:** Every change to a project status or budget creates a permanent log. Admins cannot "overwrite" history without leaving a trace.
2. **Citizen Validation:** If the government marks a project as "100% Complete" but citizens are reporting issues via the portal, the system flags the discrepancy automatically.
3. **Transparency by Default:** Data is served via public-facing APIs, making it accessible to journalists and independent auditors.



## 🛠️ Technical Stack

* **Frontend:** Next.js (App Router)
* **Backend:** Prisma ORM & Next.js API Routes
* **Database:** PostgreSQL (Neon Serverless)
* **Authentication:** NextAuth.js
* **UI/UX:** Tailwind CSS, Shadcn/UI, Lucide Icons
